# Homebridge Shelly Integration

</span>

## Plugin information

This plugin allows you to view and control your Shelly devices within HomeKit.

## Prerequisities

To use this plugin, you will need to already have:

- Node: `v18` || `v20` || `v22` || `v24`
- Homebridge: `v1.8.0` || `v2.0.0-beta.0`

## Supported devices

Actualy only few devices are supported:

- [PlusPlugIT](https://kb.shelly.cloud/knowledge-base/shelly-plus-plug-it): only switch control
- [PlusPlugS](https://kb.shelly.cloud/knowledge-base/shelly-plus-plug-s): only switch control
- [PlusPlugS_v2](https://kb.shelly.cloud/knowledge-base/shelly-plus-plug-s-v2): only switch control
- [PlusPlugUS](https://kb.shelly.cloud/knowledge-base/shelly-plus-plug-us): only switch control
